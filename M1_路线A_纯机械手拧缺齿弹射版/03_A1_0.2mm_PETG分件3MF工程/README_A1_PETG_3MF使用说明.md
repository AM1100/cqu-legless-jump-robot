# M1 路线 A · A1 / 0.2 mm / Generic PETG 分件工程

先在电脑上用 **Bambu Studio 打开 `00` 校准盘**，核对机器为 **Bambu Lab A1**、实际安装 **0.2 mm 喷头**，并确认耗材、料位和构建板。工程使用本机的 **Generic PETG @BBL A1 0.2 nozzle** 系统预设与纹理 PEI 板，其温度设置为喷嘴 **255 °C**、热床 **80 °C**、最大体积流量 **1.0 mm³/s**。若实物用的是另一种板或耗材，选正确预设并重新切片。在 Studio 中检查预览后发送到 A1，可在 Bambu Handy 管理打印任务。

## 第 0 步 · 先试孔

打开 `00_第0步_孔径校准盘_05_brake_S060_三档对比.3mf`。三件保持同一朝向，面对 Studio 热床俯视图且原点在左下时，从左到右是 **A / 0.000 mm、B / +0.050 mm、C / +0.075 mm**（X=106、128、150 mm）。对象列表也有相应编号。取下前用笔标上 A、B、C，晾凉后用实际轴或管套试插。

三件同为 0.10 mm 层高、9 壁、100% Zig zag、3 mm 外圈 Brim，关闭支撑。试切在 Z=0.60 mm 查得三个孔的外壁挤出轨迹中心线直径约 **3.817、3.919、3.969 mm**，相对于第一档放宽约 **0.10、0.15 mm**。这是刀路中心线间距，成品孔径以实测为准。

棘爪测试孔名义约 **Φ3.6 mm**。补偿按每侧偏移，新补偿约为试样当前补偿加上 `(目标直径 − 实测直径) ÷ 2`。找到合适的档位后，若需调整其他零件，优先选择相同朝向和同类配合的孔重新试插。九件正式工程的全局 XY 孔和外轮廓补偿均从 **0 mm** 起步。`04` 和 `09` 的 D 孔单独试轴，检查平边锁转。

## 局部支撑和 PETG 处理

- **四个支撑件已预设普通手动支撑，可直接预览，无需再在 GUI 点涂。**两枚齿轮只涂水平悬台，允许从模型起支撑以抵达台阶，设置顶部和底部 Z 间距 0.20 mm、支撑与模型 XY 间距 0.60 mm。机架和尾座从热床起支撑，顶部和底部 Z 间距 0.24 mm。支撑预览用「线条类型」检查，齿轮可重点看 Z=15.2、22.4 mm 附近的支撑界面。保留「普通（手动）」。
- 机架切片生成了局部支撑和完整 G-code。本机 CLI 在该复杂轮廓上记录了 ZFiller 内部诊断。正式打印前请逐层检查机架的悬板、孔边走线和支撑底脚。当前试切尚未用实物验证拆除效果和孔配合。
- 按耗材厂商标注的温度和时间烘干 PETG。大件可从干燥盒供料。若校准盘拉丝或挤出冒泡，先检查耗材干燥和喷嘴洁净，再按材料推荐温区小步调温并复切小件。优先保持系统预设的回抽和体积流量。
- 等成品冷却再从打印板取下。先从可接近的支撑脚分段拆除，再清理齿轮下方的小支撑和裙边。用尖嘴钳夹持支撑本体，避免撬在齿侧、轴孔边或机架薄壁上。清理后空载试转，再装弹性件。
