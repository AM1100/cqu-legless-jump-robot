# 🟠 这里就是【M1 验证模型实物（第 3 周 · 3D 打印手拧版）】

> **快速确认**：如果你要打印第 3 周课程作业的 **`M1` 验证模型**，直接用本文件夹即可！
> - 本方案采用 **纯机械手拧缺齿释放机构（共 9 件，全 `0.2 mm` 喷头可打）**：**不含电机、不含舵机、不含双螺旋轮、不含电池与电路板**，严格符合《Legless Jump Robot2026B.pdf》中 M1“不使用任何电子装置”的规定。
> - 如果你要找的是 **对齐第 1 周 `R1` 的手工轻木条双杆版 M1**，请看 [`../第二三周_D1与M1/`](../第二三周_D1与M1/)。
> - 如果你要打印的是 **第 4~12 周带双轮 + ESP32-C3 电控的最终竞赛样机 `M2`**，请去 [`../3D打印专用文件夹/`](../3D打印专用文件夹/)。
