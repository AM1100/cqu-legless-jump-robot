## 双轮作用与运动边界

- 原PDF第13页允许外购轮/轮轴等辅助件，第14页限定跨越隔板过程只能跳跃。双轮在区域2平地差速反向/校距，不参与任何轮驱跨板、攀板或擦板推进；起跳后双轮也必须全部离地，机体保持完整。教学评审仍以实际动作判断。
- 轮作为落地接触和俯仰旋转支点是设计功能。Φ72包络本身不能保证不倒翁：须核重心相对轮轴高度/偏置、轮距、T杆第三支点、回弹和最大倾角。轮材与辐条若仅弹性回弹而耗散不足，仍会二次弹跳。
- 原轮造型是7辐螺旋，缩放保留形状；本次没有材料有限元/疲劳/跌落试验。PLA可先核尺寸，柔性缓冲用韧性/柔性材料试样对照，不能仅换材料名称就声称落地稳定。轮对材料、结构、质量及左右刚度须配对测试。

## 必须先解决的轮轴与电机接口

- 真实N20外形/3mm输出轴不能按0.60缩小。Motor_Gear_S060原Φ3孔缩为Φ1.8；其齿根圆缩后约Φ3.375，直接粗扩到Φ3会只剩约0.1875mm径向根壁，禁止作为未经验证的正式固持办法。可采用短传动轴/3→2联轴方案，轮驱小齿轮改配约Φ2轴前须验证壁厚、强度和同轴；这只是待定接口，不是已生成配套轴。
- 轮轴孔、隔套内孔与主框孔须按实际测量配短金属轴和防脱端件。原缩放Frame内N20座也缩小，不能声称原12×10mm电机已直接装得下；左右轮驱座需重建/外置并检查齿中心距。
- Motor_Gear×2只驱轮，Servo_Gear_S060_N20_D3p2×1才是加载输入；两种齿形不能互换。全套S060齿距/轴间距共同缩放，不与原尺寸齿轮混搭。
- 各文件已XY居中、最低Z=0，不能把零件原点全部重合当装配；export_manifest保留缩放后平移。S060为各轴同缩，孔径/薄壁也缩，实际间隙、螺丝/轴不能同缩。
- T杆42×54×6，枢轴Φ3.2；两端鞋孔为(x,y)=(29/35,±20)，轮式主方案可作前接地点安装孔，Yaw鞋只是备选。N20加载座34×28×13.4、内宽12.4、轴线X/高度8.2、轴让位Φ3.4；用扎带/实物核对后固持。
- Back输出已从STEP局部卸料修复切触共边，原尺寸R0.4、缩后R0.24；所有原参考文件未改。

## 再生成与可追溯性

原13 STL/STEP解析见../analysis报告；14个原有输出与4个新增缩放轮系共18个文件的体积/状态/数量/哈希均在export_manifest.json。所有STL均单连通、闭合、正体积、绕向一致、无非流形边；仅表示网格可用，不表示齿强或整机合规通过。新增T杆/两鞋/N20座另有4个STEP。

在上一级“魔改3D打印件与代码”执行：

```bash
uv venv /tmp/legless-cad-venv
uv pip install --python /tmp/legless-cad-venv/bin/python -r requirements.txt
/tmp/legless-cad-venv/bin/python analyze_generate.py
/tmp/legless-cad-venv/bin/python write_reports.py
```

write_reports最终调用update_wheel_configuration.py，保持双轮正式装机口径；只更新本目录及01，不修改开源参考文件。CAD原作BasementCreations出处/许可须随使用保留；本目录是内部工程辅助，课程提交由成员亲自解释和撰写。
