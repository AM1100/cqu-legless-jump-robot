## 二、三线交叉核查关键结论

### 1. 原理与预算线（Antigravity，任务 `#01a1f00c`）
- **堵转边界量化**（目标单跳弹射能 `1.35 J`，`r_p = 11.879 mm`，有效行程 `53.31 mm`，`1:298` N20 堵转扭矩 `180 N·mm`）：
  - **无前置 1:3 减速**（`i = 2.857, η = 0.72`）：最大不堵转拉力仅 `31.2 N`，即使 50% 预张紧也达 **108.3% 堵转**，必堵；
  - **带前置 1:3 减速**（`i_tot = 8.571, η = 0.65`）：堵转对应拉力 `84.4 N`；50% 预张紧（`16.9 → 33.8 N`）仅占 **40.0% 堵转扭矩**（`72.0 / 180 N·mm`，峰值约 `313 mA`），完全落在 `HCC1325`（5V / 500 mA 额定、1 A 峰值）安全区。
- **M11 首轮散料 + M12 二批压簧**：
  - 废止旧版 `25~35 mm` 短拉簧（中管锁死致 Rack–Back 行程为 0）；
  - 首轮仅买 `1×3 mm` 印尼航模皮筋 + `Φ2×4 mm` 乳胶管（¥12）；
  - 若 D3 保留导杆压簧，二批选购 `65Mn / SWP-B` 长压簧 `d=0.80 × OD=8.4~8.5 (ID=6.8~6.9) × L_free=125~130 mm`（端面磨平、并紧 `32.0~35.6 mm ≤ 40 mm`，加 4 片止偏平垫片后最小有效座距 `42.89~43.49 mm`，留 `7.29~11.49 mm` 防并圈余量，全包络峰值扭矩占比 `≤ 48.5%`，验收峰力 `≤ 41 N`）。

### 2. 机械线（Codex CLI，任务 `#01a1f00e` & `#01a1f027`）
- **暂停采购 MR63ZZ 轴承（−¥12）**：STL/STEP 中主/二级齿轮与机架均为 `Φ3.00 mm` 孔，无 `Φ6` 沉孔。
- **微型螺丝（M1.6 / M2 / M2.5）实测裁决**：**不买 ¥10 混装盒**；`N20_Mount_Adapter` 为 `4×Φ3.20` 底孔 + `3×1.6` 扎带槽（无电机面板螺丝孔）；`Frame` `Φ1.50` 孔为旧件光孔非 M1.6 螺纹；`M1.6 / M2.5` 无现有设计刚需；M2 装机若沿用 E6 霍尔长圆槽，按实需合单单买 `M2×6` 机丝+平垫+螺母各 4~6 只（暂估 ¥2~4）。
- **关键配合与几何勘误**：
  - **轮驱 N20**：必选真实 `Φ2.0 mm` 减速箱输出圆轴；`Motor_Gear_S060` 齿根圆仅 `Φ3.375 mm`（扩至 Φ3 仅剩 `0.188 mm` 径向壁厚），严禁扩至 Φ3，实测出轴后渐进轻压清孔至 `Φ1.95~2.00` **齿轮与轴的固定配合**（同轴、无滑转）；取消 `3→2` 联轴套（原 STEP 端面净空仅 `1.73/1.83 mm`）。
  - **M1 / M2 / M3 / M4 / M5 / M6**：明确 `Frame` 跨度 `37.92/37.90 mm`（`40 mm` 毛坯仅外露 `2.1 mm`）、`Pitch_Prop_TBar` 为独立 `Φ3.20` 枢轴；`M2` 同轴两处锉同向 D 平面并留 `4.2 mm` 圆轴颈；`M4` 净长 `124.8×2+49.2×1 mm`（铝管重 `4.1~5.2 g`）；`M5` 定心衬套规格为 **`OD≈4.20 mm / ID≈3.55 mm`**（配 `Frame` `Φ4.20` 孔，内穿 `Φ3.5` 铝管做可滑动配合）；`M6` 仅用 304 不锈钢（剔除 H62 黄铜）。
  - **M11 侧挂窗口**：`Frame` 轮轴孔外侧固定耳 ↔ 外管前端止退可拆耳片，弦长 `31.44 → 80.90 mm`（名义齿程 `53.31 mm`），无网格穿插。

### 3. 电控线（DS，任务 `#01a1f00e` & `#01a1f022`）
- **E7' 电容最终方案**：否决 `1000 µF` 与 `470×2+100 = 1040 µF`（均踩/超 1 mF 红线），定案为 **`470µF/16V ×1 + 220µF/16V ×1 + 100µF/16V ×1 = 790 µF`**（105℃ 低 ESR，+20% 上限 `948 µF ≤ 1 mF`），就近分置于 TB6612 VM / DRV8833 VM / 舵机排针；5V 下储能仅 `9.9 mJ`（单跳 `1.35 J` 的 `0.73%`），作用严格界定为“抑制换向尖峰与负载瞬态”。
- **重量核算更新**：电容 `1.2 g → 2.7 g`，电控合计 `44.3 g → 45.8 g`，整机仍保持在 `126~132 g` 区间（距 `150 g` 红线留 `18 g+` 余量）。
