## 0.2 几何校核：锚点几何的正确算法、工作行程上限，与"M1 能验证什么 / M2 必须改什么"

> （本节编号 0.2 而非 2.x，因为它是"动手前的校核"，必须先于 §1~§4 的测量工作。）
>
> **V1.2 勘误说明（重要）**：V1.0/V1.1 的 §0.2 曾按 $\psi=\theta+180^\circ$ 建模，**忽略了锚耳的横向偏置 $w=+6$ mm**，因而错误地得出"$\theta=180°$ 取极值、$\Delta c\approx0.78$ mm、能量仅 7 mJ"的结论。经杨钊按 `01` §2 冻结公式逐度计算并互校（我方独立复算，结果一致），**正确结论是：145°→205° 全程弦长单调缩短，$\Delta c\approx6.8\sim6.9$ mm（约为原估值的 9 倍），极值点在 $\theta\approx230.2°$，不在行程内。** 原"180° 刹车"的警报**撤销**；但"有效行程偏小、M2 不能线性放大"的预警**依然成立**（见 §0.2.3）。本节已按正确几何重写。

### 0.2.1 正确的弦长公式（含横向偏置，与 `01` §2 一致）

铰链轴心为原点、后体轴线为 $+x$；前锚耳在**前体局部坐标**为 $(u,w)=(-5,+6)$ mm（相对铰链中心），后锚点 $A=(v,0)$，$v$ = 50.04 / 60.15 / 70.22 mm（A/B/C 档）。前体绕铰链转动 $\theta$ 后，锚耳在全局坐标：

$$X=u\cos\theta-w\sin\theta,\qquad Z=u\sin\theta+w\cos\theta$$

$$c(\theta)=\sqrt{(X-v)^2+Z^2},\qquad \boxed{\frac{dc}{d\theta}=\frac{vZ}{c},\quad h(\theta)=-\frac{dc}{d\theta}=\frac{v\,|Z|}{c}}$$

其中 $h(\theta)$ 即**弹簧对铰链的力臂**（$M=Fh$）。

**一条解析性质（只用这一条，不谈极值）**：$h(\theta)=-dc/d\theta=\dfrac{v|Z|}{c}$，$Z=u\sin\theta+w\cos\theta$。弦长极值点 $dc/d\theta=0 \iff Z=0 \iff \theta^*=180°-\arctan(w/u)=230.19°$（在行程之外）⇒ **145°→205° 全程 $dc/d\theta<0$，弦长单调缩短**（这是唯一保留的单调性结论）。

> **不写的三件事（采纳郑雯文定稿要求）**：① 不讨论力臂极大值位置（此前"$X=0$、144.7°"是错误结论，已删；也不用 $X=b^2/v$ 展开，避免过度推导）；② 不写"全段力臂单调衰减"；③ 不写任何由力臂推出转矩的结论（$F(\theta)$ 未实测）。

**工作行程**：$\Delta c = 6.89 / 6.82 / 6.76$ mm（A/B/C），对应力臂由 145° 处的 $h\approx7.8$ mm 变到 205° 处的 $h\approx3.7\sim3.9$ mm（仅列数值，不由此推任何转矩结论）。

> **⚠ 两条口径提醒（V1.5，采纳郑雯文复核）**
> 1. **205° 是"空载限位角"**（M1-07 限位销限制的过伸极限），**不是保证的拍地角**。真实拍地时刻/拍地角取决于接地点何时触地，必须实测（240 fps，见 §4）。
> 2. **内部限位/缓冲垫不能给整体外部冲量**（内力不改变系统动量）。起跳冲量只能来自 **M1-02 下方拍地垫与地面的真实接触反力 $F_N$**；M1-07 的作用是限制过伸、保护铰链、并在触地前后承递接触载荷，**不是"把冲量传给地面"的元件**。

### 0.2.3 能量量级估算（**仅为量级参考，不构成结论；M1 无跳高指标**）

> **⚠ 使用限制（郑雯文 + 杨钊共同要求，务必遵守）**
> 1. 下表用的是**假设的**刚度 $k$（89 或 200 N/m）与效率 $\eta=0.5$，**本项目尚无任何实测 $F$、卸载曲线、动态接地角与效率数据** ⇒ 表里的能量与跳高是**敏感性示例，不是结论，也不构成任何"够用/不够用"的判断**。实测后以实测替换。
> 2. **M1 的任务书要求是"复现机理、可演示"，并未规定跳高门槛**（150 mm 是 M2 的难度加分指标，不是 M1 指标）。**本文档不以任何跳高数字为理由建议 M1 改动** —— M1 的冻结几何照做。
> 3. 下表的唯一用途：让 D2 阶段讨论"M2 是否需要更换能量机构"时，大家手里有个**可被实测校准的量级感**。

释放功的表达式（供实测后直接代入）：$E=\int_{c_{205}}^{c_{145}}K(c-L_0)\,dc=\frac12K\left[(c_{145}-L_0)^2-(c_{205}-L_0)^2\right]$，也可近似读作 $E\approx \bar F\cdot\Delta c$。

| 档位 | $\Delta c$（**几何确定**） | $E$ @**假设** $k$=89 N/m 双筋 | $E$ @**假设** $k$=200 N/m 双筋 | 说明 |
|---|---|---|---|---|
| A | 6.89 mm | ≈26 mJ | ≈59 mJ | **敏感性示例，待实测替换** |
| B | 6.82 mm | ≈38 mJ | ≈86 mJ | 同上 |
| C | 6.76 mm | ≈50 mJ | ≈112 mJ | 同上 |

**唯一可判定的关系式（几何 + 定义式，与 $k$、$\eta$ 无关；但它本身不是"够用/不够用"的结论）**：

$$\boxed{E\approx\bar F\cdot\Delta c,\qquad b=7.81\ \text{mm}\ \Rightarrow\ \Delta c\approx 6.8\sim6.9\ \text{mm}}$$

含义仅是：**在冻结几何下，"储能 ≈ 平均张力 × 6.9 mm"**，因此能量只能靠提高 $\bar F$（加根数/换材料）或改变 $\Delta c$（改几何）来增加。
**能说到这一步为止**：M2 到底是否需要改机构、改哪种，取决于第 3 周实测的 $F(\theta)$、卸载曲线、接地角与效率 —— **本文档不做该判断，也不预设方案**（由机械线在 D2 主导提出，电控线配合选型）。

### 0.2.4 M2 放大的候选方向（仅列判据，不定方案）

| 方向 | 定性说明 | 需要机械线提供的数据 | 对电控的影响（本线关注点） |
|---|---|---|---|
| 增大锚耳力臂 $b$（保持跨铰链直线拉伸） | $\Delta c$ 随 $b$ 增大（按冻结公式：$b$=15/20/30/40 mm 时 $\Delta c$ 约 14/19/30/39 mm），但需重配 $L_0$ 并校验带长/避让 —— **可行性由机械线纸样验证** | 新的 $b$、$L_0$、$c(\theta)$ 全表 | 卷绕扭矩随角度波动加大 → 电机按 **$\max T=F(\theta)h(\theta)$ 的峰值**选型（需 $F(\theta)$ 实测量） |
| 其他机构（含机械线认为可行的任何方案） | **本线不预设**：任何会改变储能方式的方案（例如改变弹性件的受力形式）都必须由机械线先做纸样/实物验证，并明确"不引入未验证材料机理" | 受力形式、力臂/半径随角度曲线、$L_0$ | 力矩是否恒定 → 决定电流是否平稳 |

> **本线的立场**：M2 的能量机构由**机械线主导定案**，电控线只提出两个硬需求 —— ①给出 $\max T(\theta)$ 与行程，我按最大扭矩点选减速比；②**尽量让力矩随角度平稳**（否则卷绕电流峰值会顶 800 mA 上限）。纸上不做机构创新，一切以纸样/实物实测为准。

### 0.2.5 因此本文档的工程建议

1. **M1 阶段：冻结几何照做，不动任何参数**，把全部精力放在 §2~§4 的**实测**上 —— 现在缺的是数据，不是方案。**具体孔位必须在纸样试装、确认带长与避让后由机械线定孔**（§7.4 只保留计算试装值 $v$，不是加工坐标）。
2. **不新增任何机构**：不加轮毂、不改弹性件受力形式、不做纸样机构创新；M1 的任务是老老实实测出 $F$、$c$、$F_{\text{release}}$、$\eta$。
3. **实测完成后**（第 3 周）再回头用真实 $\bar F$ 与 $\eta$ 评估 M2 是否需要换机构 → 结论交 D2，由机械线主导提出方案，电控线配合选型。

## 2. 测量 M1-04 橡皮筋静态特性 $F(x)$ 与实际储能 $E$

> **先读 §0.2**：本轮同步把 Δx=25/35/45 mm 定义为"**锁止姿态下的有效弦长增量**"，所以本节要测**两条曲线**，用途不同、缺一不可：
> - **曲线 Ⅰ（材料曲线）**：单根橡皮筋自由直拉 $F\!-\!x$ → 用于**选材**（比较不同批/不同规格）。
> - **曲线 Ⅱ（整机曲线）**：装在 M1 上、随铰链角变化的 $F\!-\!\theta$ 与弦长 $c(\theta)$ → 用于**反推 M2 电机扭矩**（这是 §6 的唯一输入）。
>
> 只测曲线 Ⅰ 会漏掉几何力臂（$h(\theta)=M/F$）随角度变化，导致 M2 扭矩选小；只测曲线 Ⅱ 则无法比较材料。

### 2.1 测量原理与关键陷阱

橡皮筋的真实行为**不是**理想弹簧：$F(x) = k(x-x_0)$ 只在中等拉伸段近似成立，两端分别有"松弛段"和"硬化段"，且存在**滞回**与**应力松弛**（时间相关）。所以我们要测的是**曲线 + 三个特征值**，而不是一个 $k$。

- $x$：橡皮筋两锚点之间的**净伸长量**（相对自然长度 $L_0$），单位 mm；
- $F(x)$：在该伸长量下橡皮筋的张力，单位 N；
- 储能 $E = \int_{x_0}^{x_0+\Delta x} F(x)\,dx$（从预紧点 $x_0$ 积到工作点）。

> **陷阱 1**：M1-04 是**对称双根**，测单根后要 ×2，且两根必须同批号（不同批橡皮筋刚度可差 20%）。
> **陷阱 2**：铰链摩擦会把一部分力"吃掉"，所以**必须记录测量时的铰链角 θ**（用量角器贴在 M1-03 侧面，或背景板后画角度扇形），后续用于把 $F(x)$ 折算成铰链力矩 $M(\theta)=F\cdot a(\theta)$，$a(\theta)$ 为力臂。
> **陷阱 3**：橡皮筋会蠕变。M2 蓄能后要等遥控指令，等待期间储能会衰减 —— 必须测**保载衰减**（见 §2.4）。

### 2.2 方法 A：电子秤点测法（主方法，精度 ±2%，推荐）

**装置**：M1 拆下 M1-04 双根橡皮筋中的一根（保留锚定柱位置不变），一端固定在桌边夹具，另一端系细线 → 经定滑轮 → 竖直挂电子秤（秤上挂一个 50 g 皮重便于读数稳定）。**注意让电子秤读数方向严格沿橡皮筋轴线**。

**步骤**：
1. 用钢尺量自然长度 $L_0$（自由平放、不受力，取 3 次平均）；
2. 从 $x = 0$ 开始，每 **5 mm** 一档拉伸（用钢尺卡住定位），**停留 3 s 待读数稳定**后记录 $F$；
3. 一直拉到 $x = 60$ mm（超过 C 档 45 mm，留 33% 超程数据，用于外推 M2 需求）；
4. 再**逐级卸载** 60→0，同样每 5 mm 记一次 → 得到**加载曲线与卸载曲线**，两者之差即**滞回损耗**（决定 M2 的真实能量效率，是 D4 里"为什么取 η=0.3"的实验依据）；
5. 重复 3 轮，取平均，剔除偏差 >10% 的点。

**记录表（每根一份，双根各一份）**

| x (mm) | 0 | 5 | 10 | 15 | 20 | 25 | 30 | 35 | 40 | 45 | 50 | 55 | 60 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 加载 F↑ (N) | | | | | | | | | | | | | |
| 卸载 F↓ (N) | | | | | | | | | | | | | |

（F 换算：$F[\text{N}] = m[\text{g}] \times 9.81/1000$；若秤显示 kg 则 $F = m_{\text{kg}}\times 9.81$）

### 2.2b 曲线 Ⅱ：**整机**上测 $c(\theta)$ 与 $F(\theta)$（M2 扭矩选型的唯一依据，别省）

**装置**：M1 完整装好（按冻结锚点），夹在台钳/木夹具上，**铰链轴水平**；M1-03 侧面贴量角器（或用手机量角 App 对着拍照）；橡皮筋按 A/B/C 装好；用细线把"替代拉绳"接到电子秤（沿卷绕方向），**缓慢转动前体**改变 $\theta$。

**步骤**：
1. 从 $\theta=205^\circ$ 起，每 **10°** 一档（205→145），每档**先松手让机构自平衡**，读出该角度下橡皮筋的平衡张力 $F(\theta)$；
2. 同步用钢尺量两锚点直线距离，得 $c(\theta)$ 实测值，与 §0.2.1 公式值对照（偏差应 <1 mm，否则锚点位置与假设不符，**立即回报机械线**）；
3. 计算力臂 $h(\theta)=c(\theta)\sin\alpha$（$\alpha$ 为弹簧与后体轴线夹角）或直接由 $M=F\!\cdot\!h$ 反算；
4. 得到**释放全程的做功积分** $E_{\text{real}}=\int_{145°}^{205°}F(\theta)\,h(\theta)\,d\theta$ —— 这个值才是"能跳多高"的分母。**自检口径**：冻结几何应给出 $\Delta c\approx6.8\sim6.9$ mm、力臂 $7.8\to3.7$ mm；若实测 $\Delta c<5$ mm，先查锚点是否装错位置（见 §0.2）。

**记录表（曲线 Ⅱ）**

| $\theta$ (°) | 205 | 195 | 185 | 180 | 175 | 165 | 155 | 145 |
|---|---|---|---|---|---|---|---|---|
| $c$ 实测 (mm) | | | | | | | | |
| $c$ 公式 (mm) | | | | | | | | |
| $F$ (N) | | | | | | | | |
| $h$ 力臂 (mm) | | | | | | | | |
| $M=Fh$ (mN·m) | | | | | | | | |

> **判读**：先单独看 $h(\theta)$ 的实测值是否落在公式值附近（$h$ 由 145° 的 7.8 mm 降到 205° 的 3.7 mm，此为几何量，可独立核对）；再看 $M(\theta)=F(\theta)\cdot h(\theta)$ **是否出现变号**（$h$ 与 $F$ 理论上均为正，故 $M$ 应全程为正）。**在 $F(\theta)$ 未实测前，不对 $M$ 的衰减快慢、峰值位置下任何结论。**
> - 若 $h$ 在 205° 前就掉到 0 或变号 ⇒ 锚耳装反/装错位置（横向偏置 $w$ 方向错），回 §0.2.1 复核；
> - 若 $h$ 与理论值的偏差 >15% ⇒ 锚孔实际位置与图纸不符，**先改孔、再做 §4 跳跃测量**，否则跳高数据会系统性偏低。

### 2.3 方法 B：砝码加载法（校核用，无需拉力计，精度 ±5%）

把 M1 按蓄能姿态固定（前体锁止销已入坎），在 M1-06 拉绳末端经定滑轮挂砝码，**逐级加 5 g**，每级记录拉绳水平位移（卡尺）。当位移突然跳变（挂钩开始让位）时即为**满载脱扣点**，此时砝码重量给出 $F_{\text{release}}$（见 §3）。此法同时也是 §3 的主方法，可与方法 A 交叉验证：*理论上 A 档/C 档的 $F$ 值应与对应砝码质量吻合*。

### 2.4 储能计算（梯形积分）与保载衰减

$$E = \int_{x_0}^{x_0+\Delta x} F(x)\,dx \approx \sum_{i} \frac{F_i + F_{i+1}}{2}\,\Delta x_i$$

把 §2.2 的表格代入，即可得到三档储能：
- A 档：$x_0 \to x_0+25$ mm
- B 档：$x_0 \to x_0+35$ mm
- C 档：$x_0 \to x_0+45$ mm

**保载衰减测试（M2 专用前提，15 分钟，别省）**：把橡皮筋拉到 C 档并锁止，在 0 / 15 / 30 / 60 / 120 s 各读一次挂钩上的张力（用方法 A 的秤串在"替代拉绳"上，保持锁止状态测量）。

$$\text{衰减率} = \frac{F(0)-F(120)}{F(0)}\times 100\%$$

- 若 <5%：M2 可以"蓄能后任意等待"，遥控节奏自由；
- 若 5~15%：M2 需在蓄能完成后 **10 s 内释放**，控制程序里加"蓄能完成后自动倒计时 10 s 释放"或语音/蜂鸣提示；
- 若 >15%：说明橡皮筋材质不行，**换材质（乳胶圈→硅胶管或更粗的弹力绳）**，这是必须上报的选材问题。

### 2.5 量级自检（**仅用于判断"测出来的数是否荒谬"，不作为改方案依据**）

- M1 目标质量 30 g；**M1 无跳高指标**（这里只是取一个"能看出明显跃起"的量级作参照，例如 50~100 mm）→ 需离地机械能 $E_{\text{out}} = mgh \approx 0.015\sim0.029$ J；
- 若机械效率 **假设** η≈0.5（**未实测**），则需储能 $E \approx 0.03\sim0.06$ J；
- **注意这个 $E$ 是"能跳起来"的反推量级，实际做功受 §0.2 的 $\Delta c$ 与未实测的 $F(\theta)$ 共同决定**：用 $E\approx\bar F\cdot\Delta c$ 反推，$\Delta c=6.8$ mm 时需 $\bar F\approx4\sim9$ N。**"这个张力是否容易实现"要等实测 $F$ 才知道**，本文档不作判断。

> **自检口径（只用于发现"测错了"，不是性能结论）**：
> - 实测 $E_{\text{real}}$ 若与 $E\approx\bar F\Delta c$ 的量级自相矛盾（例如 $\bar F=8$ N 而 $E_{\text{real}}$ 只有 3 mJ）→ 说明测量或锚点装配有问题，先复查；
> - 若明显跳不起来 → 依次查：锚点装配（§0.2）、橡皮筋老化、铰链摩擦、**触地垫/缓冲件吸能过多**、接地时刻是否过早/过晚；
> - 若翻筋斗失控 → 查 M1-07 限位与重心/惯量。
> **M1 只要"能明显跃起、可重复、可拍清楚"就达标，不追求跳高。**

## 3. 测量 M1-05 挂钩的满载脱扣力 $F_{\text{release}}$ 与脱扣行程 $s_{\text{trigger}}$

这两个数是**整个电控选型的关键输入**：$F_{\text{release}}$ 决定舵机/电机能不能脱扣，$s_{\text{trigger}}$ 决定舵机摆臂长度或电机反转圈数。

### 3.1 $F_{\text{release}}$（准静态，最优方法）

**装置**：M1 按**满载蓄能状态**（C 档，最不利工况）装好并竖直/水平固定牢（用胶带绑在木块上，全程不许被人手扶）。

**步骤**：
1. M1-06 拉绳沿**纯水平方向**（这是合规红线：任何向上的分力都会被判"人力提拉助跳"）接到定滑轮，转竖直；
2. 托盘中逐级放砝码，**每级 5 g，间隔 5 s**（快速加载会产生动态冲击，读数虚高）；
3. 观察挂钩：**当锁止销开始让位（肉眼可见的相对位移 ≥0.5 mm）的瞬间**，停止加载，记录当前总质量 $m_{\text{rel}}$；
4. $F_{\text{release}} = m_{\text{rel}}\times 9.81/1000$（N）；
5. **重复 5 次**（每次重新装配、重新锁止），取均值 ± 标准差。标准差 >15% 说明挂钩几何不稳定，**先在机械上解决，不要靠加大舵机扭矩硬顶**。

> **工程经验值参考**：一个好的"销-坎"自锁机构，$F_{\text{release}}$ 应满足 $F_{\text{release}} \approx (0.2\sim0.5)\,F_{\text{spring}}$。若实测 $F_{\text{release}} > 0.8 F_{\text{spring}}$，说明楔角太钝，M2 用小舵机顶不动（见 §8.2 楔角设计）。

### 3.2 $s_{\text{trigger}}$（脱扣行程）

**口径已统一（第 2 周同步）**：M1-06 采用**短行程 2~3 mm 拔销/滑脱式**挂钩，因此目标设计值就是 $s_2 = 2\sim3$ mm，而不是"能拉多少算多少"。用游标卡尺量"拉绳从初始张紧位置到挂钩完全让位"的直线距离；或从 240 fps 视频中读拉绳标记点的位移（精度 ±1 mm）。

**分级记录**：`开始让位 s₁`（脱扣动作开始，约 1 mm）、`完全脱开 s₂`（销自由，约 2~3 mm）；M2 舵机行程取 $1.3\,s_2 \approx 3\sim4$ mm。

> **⚠ 对脱扣方案的反向影响（重要）**：$s_2$ 只有 2~3 mm，意味着
> - **方案甲（舵机拨叉）非常合适**：摆臂只需 5 mm、转角 ±10° 即可，扭矩余量极大；
> - **方案乙（电机反转过死点）变得不合适**：N20 减速比 1:298 时，2~3 mm 的精细行程对应电机轴仅转约 0.1 圈，**反转量难以精确控制**，很容易过冲把销顶飞或顶不脱。⇒ **进一步确认"v1 用舵机、v2 才考虑反转"的决策（§7.3）**。
>
> **另一条硬要求**：脱扣后拉绳必须**脱离或完全松弛**（"拉脱即分离"/带松弛余量），否则起跳腾空段拉绳仍在拽机体 → 既影响跳高跳距，也容易被判定为"外力牵引"。台架验收时按 §12.3 第 8 项检查。

### 3.3 脱扣瞬态时间（对 M2 的"释放延迟"极重要）

从 240 fps 视频量：挂钩开始让位 → 销自由 → 后体拍地 → 离地的总时间链。

$$\Delta t_{\text{release}} = t_{\text{离地}} - t_{\text{脱扣开始}}$$

典型值 10~35 ms。**M2 的控制程序里必须给出这个"指令→离地"延迟**，否则遥控操作手感极差（操作者会提前/滞后按压），且 4 分钟内多次尝试时会误判"没跳"而重复操作。把这个值写进 D4 的控制时序图。

## 4. 用手机 240 fps 测跳跃运动学：$\Delta t,\ v_0,\ \theta,\ h,\ d$

### 4.1 逐帧标注口径（三人必须统一，否则数据不可比）

| 量 | 定义 | 判读帧 |
|---|---|---|
| 起跳时刻 $t_0$ | **后体拍地垫（M1-07 区域）最后接触地面的那一帧** | 触地点与地面阴影/接触线分离的第一帧 |
| 离地质心 $G_0$ | 主铰链轴心（M1-03 螺栓中心）在该帧的位置 | ——（用铰链中心代替质心，见 §4.4 修正） |
| 最高点 | 铰链中心 y 坐标最大帧 | |
| 落地时刻 $t_1$ | 任一部分再次接触地面的第一帧 | |
| 水平跳距 $d$ | 起跳点地面十字准星 → 落地触地点中心的水平距离 | 卷尺直接量（视频外量更准） |

### 4.2 数据处理公式

1. **比例换算**：$\Delta y[\text{mm}] = \Delta p_{y}[\text{px}] \times k_{px}$（§1.3 标定）。
2. **离地初速度**：取 $t_0$ 后连续 3 帧（$t_0, t_0+\Delta t_f, t_0+2\Delta t_f$）的 $G$ 位置做最小二乘直线拟合（或二阶抛物线拟合），取 $t_0$ 处斜率：

$$v_0 = \sqrt{v_{0x}^2+v_{0y}^2},\qquad \theta = \arctan\!\left(\frac{v_{0y}}{v_{0x}}\right)$$

   *不要用相邻两帧单差分*（4.17 ms 间隔下噪声极大）；一定用多帧拟合。
3. **交叉验证 $g$**：对腾空段（$t_0\to t_1$，无接触）做抛物线拟合 $y(t)=a t^2+bt+c$，检查 $|2a| \approx 9.8\ \text{m/s}^2$（容差 ±15%）。**若偏差 >30%，说明帧率不是 240 fps 或像素标定错了 —— 全部重拍。**
4. **跳高**（质心升高）：$h = y_{\max}-y_{G_0}$；并用能量法校核 $h \approx v_{0y}^2/(2g)$，二者差 >20% 需查原因（多半是 $v_0$ 拟合段选到了已触地帧）。
5. **机械效率**：

$$\eta = \frac{\frac12 m v_0^2}{E_{\text{stored}}}$$

   $m$ 用电子秤实测（含 M1-08 背板）。这个 η 是 D2/D4 里所有能量预算的分母，**也是 R2 里"设计点→实测→迭代"闭环的第一个数字**。
6. **功率放大**（R1 的核心论点，此处给出实测）：

$$P_{\text{peak}} \approx \frac{E_{\text{stored}}}{\Delta t_{\text{release}}},\qquad \text{放大倍数} = \frac{P_{\text{peak}}}{E_{\text{stored}}/T_{\text{wind}}}$$

### 4.3 测量批次规范

- 每档（A/B/C）**各 7 次**，剔除最大/最小后取 5 次均值 ± 标准差；
- 每次跳跃前**重新锁止、重新量拉伸量**（用手拉的方式重复加载会引入 ±3 mm 误差）；
- 记录**环境**：室温与湿度（橡皮筋刚度随温度变化约 1%/℃），至少记一次；
- 落地后 M1 若翻滚/解体，本次数据标记为"无效（非正常起跳）"，但**保留**并注明原因（翻滚本身是 M2 姿态控制的已知风险）。

### 4.4 用铰链中心代替质心的修正

铰链中心不是质心。用**吊线法**测真实质心：用细线在 M1 上找两点分别悬挂，两垂线交点即质心 $G$（拍照片、标在 D1 图上）。测出 $G$ 与铰链中心的偏移 $(\delta_x,\delta_y)$ 后，刚体平面运动下：

$$v_G = v_{\text{铰链}} + \omega \times r_{G/\text{hinge}}$$

视频里同时读**铰链位移**与**杆体转角 $\varphi(t)$**，即可修正 $v_G$；$\omega \approx d\varphi/dt$（相邻帧转角差）。**这一条是 M2 空中姿态（会不会翻过头）分析的关键**，也是 D1 图 4 与 R2 动力学章节的素材。

## 6. 由实测反推 M2 电控执行器参数（选型的算法流程）

### 6.1 电机扭矩与减速比

卷筒半径 $r$（建议 4~5 mm，见 §7.1），卷绕时最大所需扭矩：

$$T_{\text{need}} = \frac{F_{\max}\cdot r}{\eta_{\text{drum}}} \times K_s$$

取 $\eta_{\text{drum}} = 0.8$（卷筒+导向环摩擦）、安全系数 $K_s = 2.0$（覆盖橡皮筋超程与卡滞）。

**算例（等实测值代入）**：若 $F_{\max}=4.5\ \text{N}$、$r=5\ \text{mm}$：
$$T_{\text{need}} = 4.5\times0.005/0.8\times2.0 \approx 0.056\ \text{N·m} \approx 0.57\ \text{kgf·cm}$$

对照 N20 5V 减速电机典型规格：**1:298 版**堵转扭矩 ≈1.5 kgf·cm、额定 ≈0.4~0.5 kgf·cm → **安全系数约 3~4 倍，选 1:298（或 1:150 视转速需求）**。

### 6.2 卷绕速度与时间预算

$$v_{\text{line}} = \frac{2\pi r\, n}{60}\ \text{(mm/s)},\qquad t_{\text{wind}} = \frac{L_{\text{wind}}}{v_{\text{line}}}$$

1:298 版空载输出转速约 30 rpm、负载后约 20 rpm，$r=5$ mm → $v\approx 10$ mm/s → 45 mm 行程约 **4.5 s**（很快）。若希望更慢以减小电流冲击，用 PWM 降占空比到 60~70%，同时把启动浪涌压下去。

> **行程口径修正（第 2 周同步）**：$L_{\text{wind}}$ = **锁止姿态的弦长增量**（A/B/C = 25/35/45 mm，是 $\Delta c$ 不是直拉伸长）+ 拉绳从锚点到卷筒的走线路径长度。（若 M2 阶段机械线改成更大的锚耳力臂 $b$，$\Delta c$ 会相应变长，届时按新 $c(\theta)$ 表重算 $t_{\text{wind}}$。）

> **时间预算结论**：单次"卷绕 5~10 s + 转向 5 s + 释放 0.05 s + 复位 10 s" ≈ 20~25 s，4 分钟可支持 **6~8 次尝试**，工程上按 3~4 次设计，余量充足。

### 6.3 工作电流校核（≤300 mA 目标）

$$I_{\text{work}} \approx \frac{T_{\text{need}}\cdot \omega}{U \cdot \eta_{\text{motor}}} + I_0$$

用厂家特性曲线的实操办法更简单：**买 2 个候选型号（1:150 与 1:298），在我方台架上实测**（§12.3），把"卷绕全过程电流曲线"作为最终选型依据，而不是靠数据手册。判据：

- 卷绕稳态电流 **≤150 mA**（留 MCU 60 mA + 舵机峰值 200 mA 的余量）；
- 启动/换向瞬时峰值 **≤800 mA**（靠 470 µF + PWM 软启动压）；
- **不允许出现堵转**（见 §12.3 电流保护门限设定）。

**设计要点（每条都是踩过坑的）**：

3. **线必须走"下表面"**：与 M1-06 的底部导向环同一平面，保证拉力线通过铰链轴下方 → 产生使前体上仰的力矩（这是背弓蓄能的来源），而不是把两杆往一起挤。
4. **电机与卷筒之间不用联轴器，直接让电机输出轴当卷筒轴**（省 3 g、省同心度问题），卷筒用紧配合 + 侧向 M2 紧定螺钉。
5. **必须设"张力过载保护"**：卷绕线上串一段 0.6 mm 硅胶管做**摩擦打滑离合器**，或把卷筒与轴做成摩擦配合（预紧力调到 1.5×$F_{\max}$）—— 这样即使程序失控持续卷绕，也不会把电机顶到堵转、不会把碳杆拉断、不会把 5V 母线拉垮。**这是防"堵转拉垮单片机"最省钱的一招，比加电容有效得多。**

两个方案的机械接口不同，**所以孔位必须现在就一起留**（这是本文档对机械线最实的一条建议）：

**方案甲：4.3 g 微舵机拨叉**（v1 主推）
- 舵机座尺寸：留 **24 × 12 mm 平面 + 2×M2 孔**（适配 4.3~9 g 舵机，间距 20 mm）；

- 舵机输出轴到棘爪作用点距离 $a$，则所需舵机扭矩 $T_{\text{servo}} \ge 2 F_{\text{release}}\,a$（2 倍余量）。算例：$F_{\text{release}}=1.5$ N、$a=6$ mm → $T\ge 0.018$ N·m ≈ 0.18 kgf·cm，4.3 g 舵机（≈0.8 kgf·cm）绰绰有余；

- **决策建议**：M2 v1（第 5~6 周）用方案甲保证 D4/MVP 能演示；**方案乙作为 R2（第 9 周）的减重/简化迭代项**，先在台架上单独验证 30 次连续脱扣成功率 ≥95% 再上机。

## 8. 单向锁止 + 遥控脱扣机构的设计要点（把 M1-05 变成 M2 的棘轮-棘爪）

### 8.1 为什么要改成棘轮

M1-05 是**双向**的销-坎（手动挂、手动拉脱）。M2 必须：
1. **卷绕时单向自动锁止**（一格一格自动落入，无需人手）；
2. **断电后保持锁止**（不能靠电机保持扭矩，否则 500 mA 预算立刻崩）；
3. **一条遥控指令就能脱扣**。

这三点合起来，标准解法就是**棘轮-棘爪 + 拨叉**。

### 8.2 楔角自锁判据（决定 $F_{\text{release}}$ 与误脱扣率）

销与坎接触面法线与拉力方向的夹角记 $\alpha$（楔角），摩擦角 $\varphi=\arctan\mu$（尼龙-钢 $\mu\approx0.15\sim0.25$ → $\varphi\approx8.5^\circ\sim14^\circ$）：

- **自锁条件**：$\alpha < \varphi$ → 拉力再大也顶不开，绝对安全，但脱扣需要额外拨动；
- **可脱扣条件（靠拨叉）**：$\alpha$ 取 12~20°，此时把销"抬起"所需力

$$F_{\text{lift}} \approx F_{\text{spring}}\cdot\frac{\sin(\alpha-\varphi)}{\cos\varphi} \quad (\alpha>\varphi)$$

**算例**：$F_{\text{spring}}=4.5$ N、$\alpha=18^\circ$、$\varphi=12^\circ$ → $F_{\text{lift}}\approx4.5\times\sin6^\circ/\cos12^\circ\approx0.49$ N。舵机 $a=6$ mm 时需 0.03 N·m —— 极轻松。反之若 $\alpha=10^\circ<\varphi$，理论上 $F_{\text{lift}}\to0$ 但会被摩擦锁死，实测会"卡住不脱"，这是最常见的 M2 装配故障。

> **装配调试口诀**：**先做纯自锁（$\alpha<\varphi$）验证不会误脱扣；再靠拨叉"抬起"销（不是硬拉）**。用"抬起"而非"硬拉"，$F_{\text{lift}}$ 可以降到 $F_{\text{spring}}$ 的 1/10，是省电与省重量的关键。

### 8.3 回位与安全

- 棘爪必须有**回位弹簧**（0.2 mm 弹簧钢丝，预紧 0.2 N），否则脱扣后棘爪不复位 → 下次无法锁止；
- 脱扣后**电机必须立即停止**（否则线还在被卷、会拉扯已脱离的销）；
- 加"**上电不动作**"：上电 500 ms 内所有输出禁用，等待遥控握手，防止上电瞬间卷绕把 M1/M2 弄坏。
- **"拉脱即分离"（第 2 周同步，硬要求）**：短行程拔销式挂钩脱扣后，卷绕线必须**与机体分离或完全松弛**（做法：线上做一对可自动脱开的插销环；或卷绕后留 5~8 mm 松弛余量）。否则腾空阶段线仍在拽机体 → 既损失跳高跳距，也可能被判"外力牵引"。这条在 §12.3 第 8 项验收。

## 10. HCC1325 电池 + ESP32-C3 的重心布局建议

### 10.1 布局原则（按优先级）

1. **质心靠近主铰链轴**：空中转动惯量 $I$ 越小，姿态越可控、翻转角速度越大（有利于"背弓→拍地"的能量传递），但也越容易翻转过度。**目标：整机质心落在铰链孔后方 5~10 mm、离底面高度 ≤20 mm**。

## 11. 过渡提醒：储能必须按"实测 + 质量"重新标定（M1 数据不能直接线性放大）

### 11.1 放大系数

$$E_{\text{M2}} = E_{\text{M1}}\cdot\frac{m_{\text{M2}}}{m_{\text{M1}}}\cdot\frac{h_{\text{M2}}}{h_{\text{M1}}}\cdot\frac{1}{\eta_{\text{ratio}}}$$

- $m_{\text{M2}}/m_{\text{M1}} \approx 150/30 = $ **5 倍**（若 M1 做 25 g 则 6 倍）；
- $h_{\text{M2}}/h_{\text{M1}}$：**M1 无跳高指标**（任务书只要求可演示）；M2 至少要过 H≥10 cm 的挡板、争取 H≥15 cm/D≥30 cm 的难度分 ⇒ 按 **M2 需跳 150~200 mm** 计；
- $\eta$ 会因 M2 摩擦件增多而下降，取 0.7 倍惩罚。

**结论：仅按质量与跳高，M2 需要的储能量就约是 M1 的 6~8 倍。**

> **⚠ 与 §0.2.3 的交叉影响（务必一起读）**：上式里的 $E_{\text{M1}}$ **必须用 §2.2b 的整机做功积分 $E_{\text{real}}$（实测量），不得用理想值 $\frac12kx^2$，也不得用本文档的估算值**。按冻结几何 $\Delta c\le6.9$ mm，即使 $\bar F$ 很大，**每档的能量上限也被 $E\approx\bar F\cdot\Delta c$ 卡住** ⇒ M2 若要 0.6~0.8 J，需要的 $\bar F$ 是几十牛量级，靠"加橡皮筋根数"不现实。**这条是 D2 的判据，不是本文档的结论**；M2 的具体机构由机械线在实测定标后主导提出（§0.2.4）。

**定量算例（纯示意，用于说明"为什么根数解决不了问题"）**：设 M1 实测 C 档 $\bar F=8$ N ⇒ $E\approx8\times0.0068=54$ mJ；M2 按 6~8 倍需 0.32~0.43 J（若按 η 惩罚与 200 mm 跳高则接近 0.7 J）⇒ 需 $\bar F\approx47\sim100$ N ⇒ 折合 6~12 根以上且 $\Delta c$ 仍只有 6.9 mm。**此时真正的瓶颈是 $\Delta c$（几何），不是根数（力）。**

### 11.2 M1 阶段建议补做的两组测量（**只为拿数据，不改方案**）

| 试验 | 内容 | 输出 | 用途 |
|---|---|---|---|
| **加档试验 A'** | 在 A 档位置**并联 3 根**同规格橡皮筋拉伸至 45 mm，重复 §2、§4 测量 | 3 根并联的实测 $F$、$E_{\text{real}}$、跳高 | 验证"多根并联"的实际增益与重量代价（**不预设结论**） |
| **超程试验 D** | 单组橡皮筋拉伸至 **70 mm**（若材料允许）测力与储能 | 大行程下的 $F(x)$ 非线性程度、是否屈服 | 判断弹性件在大行程下是否仍可用 |

**判读（数据出来后由机械线主持决策，本线只提供量级判据）**：
- 若 3 根并联的实测 $\bar F$ 明显高于 1 根的 3 倍（叠线/挤压效应）→ 并联效率要打折，D2 预算需上调；
- 若材料在 70 mm 处屈服或严重非线性 → M2 选材受限，需与机械线一起重新选弹性件；
- **M1 本身不因上述结果改方案**（冻结几何照做）。

> **一句话**：M1 阶段我们缺的是**实测数据**，不是新机构。任何"换机构"的讨论都等 §2~§4 的数据落地后，在 D2 由机械线主导提出、电控线配合选型。
